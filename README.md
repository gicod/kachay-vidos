# Video Downloader — прототип

Настольный прототип на Python + PySide6:
- тёмная тема;
- отдельные каталоги YouTube и Instagram;
- выбор качества отдельно для каждой платформы;
- вставка нескольких URL (по одному на строку);
- очередь задач, прогресс и журнал;
- настройки сохраняются в `config/settings.json`.

## Запуск

Требуется Python 3.10+.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

### FFmpeg (обработка видео и звука)

Проект использует `imageio-ffmpeg`: при установке зависимостей команда `pip install -r requirements.txt`
устанавливает FFmpeg-бинарник для поддерживаемой платформы, а приложение передаёт его путь в `yt-dlp`.
Поэтому системная установка FFmpeg и настройка `PATH` обычно не нужны.

Если приложение сообщает «Не найден FFmpeg», активируйте виртуальное окружение и выполните:

```powershell
python -m pip install -U imageio-ffmpeg yt-dlp
```

Затем полностью закройте и снова запустите приложение. Проверить, доступен ли системный FFmpeg, можно командой:

```powershell
ffmpeg -version
```

Если предпочитаете установить FFmpeg отдельно в Windows, можно использовать `winget` (если он доступен):

```powershell
winget install --id Gyan.FFmpeg -e
```

После системной установки закройте и заново откройте терминал, чтобы Windows обновила `PATH`.
Приложение сначала ищет FFmpeg в `PATH`, а затем проверяет бинарник из пакета `imageio-ffmpeg`.

Загружайте только контент, к которому у вас есть разрешённый доступ.

## Примечания
Это ранний прототип. Загрузка выполняется через `yt-dlp`; поддержка Instagram зависит
от доступности публикации и требований платформы. Для приватных материалов может
потребоваться отдельная настройка авторизации. Не обходите ограничения доступа.
