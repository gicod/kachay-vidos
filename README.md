# Video Downloader — прототип

Настольный прототип на Python + PySide6:
- тёмная тема;
- отдельные каталоги YouTube и Instagram;
- выбор качества отдельно для каждой платформы;
- вставка нескольких URL (по одному на строку);
- очередь задач, прогресс и журнал;
- настройки сохраняются в `config/settings.json`.

## Запуск

Требуется Python 3.10+.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

### FFmpeg (обработка видео и звука)

Проект использует `imageio-ffmpeg`: при установке зависимостей команда `pip install -r requirements.txt`
устанавливает FFmpeg-бинарник для поддерживаемой платформы, а приложение передаёт его путь в `yt-dlp`.
Поэтому системная установка FFmpeg и настройка `PATH` обычно не нужны.

Если приложение сообщает «Не найден FFmpeg», активируйте виртуальное окружение и выполните:

```powershell
python -m pip install -U imageio-ffmpeg yt-dlp
```

Затем полностью закройте и снова запустите приложение. Проверить, доступен ли системный FFmpeg, можно командой:

```powershell
ffmpeg -version
```

Если предпочитаете установить FFmpeg отдельно в Windows, можно использовать `winget` (если он доступен):

```powershell
winget install --id Gyan.FFmpeg -e
```

После системной установки закройте и заново откройте терминал, чтобы Windows обновила `PATH`.
Приложение сначала ищет FFmpeg в `PATH`, а затем проверяет бинарник из пакета `imageio-ffmpeg`.

Загружайте только контент, к которому у вас есть разрешённый доступ.

## Примечания
Это ранний прототип. Загрузка выполняется через `yt-dlp`; поддержка Instagram зависит
от доступности публикации и требований платформы. Для приватных материалов может
потребоваться отдельная настройка авторизации. Не обходите ограничения доступа.

## Автоматическая обработка очереди

Нажмите **«Начать загрузку»** один раз: приложение автоматически перейдёт к следующим задачам со статусом «В очереди», когда текущая загрузка завершится. Одновременно запускается не более одной задачи для каждой платформы; YouTube и Instagram могут обрабатываться параллельно. Задачи со статусом «Ошибка» автоматически не повторяются, чтобы не зациклить очередь. Чтобы повторить неудачные загрузки, нажмите «Начать загрузку» ещё раз.


## Остановка загрузок

- **«Отменить выбранное»** останавливает выбранные активные задачи или отменяет выбранные задачи, которые ещё не начали скачиваться.
- **«Остановить все»** запрашивает остановку всех активных загрузок и приостанавливает автоматический переход к следующим ссылкам.
- Нажмите **«Начать загрузку»**, чтобы продолжить очередь. Задачи со статусом **«Отменено»** при ручном запуске снова добавляются в работу.
- Если отменить активную загрузку, временные файлы сохраняются, а `yt-dlp` при следующем запуске пытается продолжить загрузку с уже скачанной части. Успешно завершённые задачи повторно не запускаются.

Остановка выполняется кооперативно: приложение сообщает `yt-dlp` об отмене и завершает текущую операцию при ближайшем обновлении прогресса. В зависимости от сетевого запроса это может занять некоторое время.

## Скачивание изображений и каруселей Instagram

Если публикация Instagram содержит несколько изображений, `yt-dlp` загружает доступные элементы публикации. После загрузки приложение автоматически раскладывает файлы по папкам:

- видео сохраняются в указанную папку Instagram;
- изображения (`.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`, `.gif` и другие распространённые форматы) — в подпапку `Images` внутри папки Instagram.

Например, при стандартных настройках фотографии будут находиться в `Videos/Instagram/Images`. Если Instagram ограничивает доступ к публикации или требует авторизацию, загрузка может завершиться ошибкой; приложение не обходит ограничения доступа.

## Чистые логи

Цветовые ANSI-последовательности, которые `yt-dlp` использует для оформления терминального вывода, удаляются перед отображением. Например, сообщение `Downloading item [0;32m1[0m of [0;94m6[0m` отображается как обычный текст `Downloading item 1 of 6`.


## Название видео и плейлисты YouTube

- Название текущего видео остаётся первой строкой в колонке «Результат». Скорость/сведения о загрузке и итоговое сообщение показываются ниже, не затирая название.
- Если добавить ссылку на YouTube-плейлист (включая ссылку вида `watch?v=...&list=...`), при запуске очередь сначала получает список роликов и заменяет ссылку на отдельные задачи — по одной на каждое доступное видео.
- Название каждого ролика показывается в соответствующей задаче до начала загрузки. После раскрытия плейлиста все ролики проходят через общую очередь и скачиваются по правилам параллельности приложения.
- Видео из плейлиста сохраняются в отдельную папку `Playlists/<Название плейлиста> [ID плейлиста]` внутри основной папки YouTube. Например: `Videos/YouTube/Playlists/Мой плейлист [PLxxxx]/`. ID помогает отличать плейлисты с одинаковыми названиями.
- Разбор плейлиста выполняется в отдельном потоке, поэтому интерфейс остаётся отзывчивым. Его можно отменить кнопкой «Остановить все» или «Отменить выбранное».
- Для недоступных/удалённых роликов задача может быть пропущена: это зависит от информации, которую возвращает `yt-dlp`.


## История загрузок (SQLite)

Вкладка **«История»** показывает файлы, которые успешно сохранены на диск. После завершения загрузки каждый файл автоматически записывается в локальную базу `data/download_history.db` (SQLite): дата, платформа, название, исходная ссылка, путь и размер. Изображения Instagram также учитываются как отдельные файлы. История сохраняется между запусками приложения. Можно искать записи, открыть выбранный файл или удалить только запись из истории — сам файл на диске при этом не удаляется.
